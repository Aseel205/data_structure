# Data Structures - Course Projects

This repository contains projects from the Data Structures course, covering a range of theoretical and practical concepts. Each assignment explores key topics such as complexity analysis, data structures implementation, algorithm optimization, and compression techniques.

## Assignments Overview

### 1. Complexity Hierarchy
- Analyze functions and classify them into a complexity hierarchy using Big-O, Theta (Θ), and Omega (Ω) notations.
- Prove function relationships using formal asymptotic definitions.
- Solve recurrence relations and explore the properties of asymptotic bounds (transitivity, reflexivity, etc.).

### 2. Air Collision Prevention System
- Design and implement an efficient data structure to track and manage airplanes in a 2D space.
- Ensure a minimum distance threshold between planes using optimized spatial data structures.
- Analyze the time complexity of operations and optimize performance.

### 3. Advanced Data Structures Implementation
- Implement modified versions of core data structures covered in class.
- Develop efficient data manipulation techniques while adhering to strict Java constraints (no built-in collections except List, LinkedList, and ArrayList).
- Theoretical analysis of algorithmic performance and pseudo-code formulation for problem-solving.

### 4. Compression & Sorting Algorithms
- Implement Huffman Encoding and Lempel-Ziv 78 Decoding algorithms for data compression.
- Perform an amortized analysis on selected operations.
- Implement and compare various sorting algorithms, including:
  - Insertion Sort
  - Merge Sort
  - Heap Sort
  - Quick Sort
  - Bucket Sort
  - Radix Sort

## Technologies Used
- **Language**: Java (Version 17)
- **Concepts**: Data Structures, Algorithm Design, Complexity Analysis, Optimization
