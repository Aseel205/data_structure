# Data Structures

This repository contains projects from the Data Structures course, showcasing in-depth exploration of:

- **Algorithm Analysis**: Understand growth rates, solve recurrences, and explore amortized analysis.
- **Core Data Structures**: Implement and analyze stacks, queues, binary search trees, AVL trees, B-trees, hash tables, and skip lists.
- **Advanced Topics**: Dive into Bloom filters, priority queues, efficient sorting algorithms (e.g., Quicksort, linear-time sorting), and graph algorithms (e.g., BFS, DFS, MST).

Each project is designed to deepen understanding of theoretical concepts and their practical applications.
